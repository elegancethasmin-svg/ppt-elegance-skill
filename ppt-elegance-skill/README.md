# PPT Elegance Skill

[English](README.en.md) · [MIT](LICENSE) · [配置与 API](docs/API.md) · [命令与示例](docs/USAGE.md)

根据资料组织内容、选择风格、生成逐页提示词，并将检查过的图片组装为演示文稿。适用于技术讲解、项目答辩、团日活动、校园实践、文化传承和医学科普。

**内容模式 × 视觉风格 × 页面版式** 分开配置。团日活动可以使用红色青春或传承文化，技术项目可以使用蓝金科技或黑色芯片。无需绑定某家图像服务。

| 能力 | 当前状态 |

| 8 个风格包、5 类内容模式、14 类页面 | 已提供，可修改扩展 |
| 页面规格校验、逐页提示词组装 | 可执行 Python 脚本，无第三方依赖、无网络 |
| 调用环境已有图像工具 | 智能体根据实际工具能力调用；本仓库不附带图像服务 |
| 图像 API 示例 | 同步 JSON 文生图、内嵌 base64 PNG；离线模拟测试覆盖，未连接真实付费服务验证 |
| PPTX、PDF、PNG ZIP、总览和备注 | 可执行图片型打包脚本，需安装可选依赖 |
| 中文纠错、流程核验、图像审美检查 | 智能体或人工检查，不是自动保证 |
| 多图参考、局部编辑、异步 API | 可用已有工具实现；示例 API 适配器尚未实现 |
| 一键读取任意文档到成品、自动批量重试 | 没有提供这样的全自动程序 |
| 原生可编辑文字、图表、动画 | 不由图片型打包器提供，需使用相应演示文稿工具 |

**整页图片型 PPT 的文字不能单独编辑。** 生成图片可能存在错字、错误箭头或布局偏差，必须逐页复核。标记为“已检查”不等于事实自动得到验证。

## 选择一种使用路径

### 1. 只生成提示词：不需要 API

向智能体提供资料、主题、页数、风格和讲解时长，要求输出大纲、页面规格和逐页提示词。将提示词复制到你选择的图像平台，保存每页图片，再交回智能体检查和组装。

```text
使用 $ppt-elegance-skill，采用“只生成提示词”路径。
根据我提供的活动策划，设计12页团日活动PPT，风格为红色青春。
这是活动计划，尚未举办。不要编写实际人数和成果。
输出大纲、每页文案、讲解备注及可直接复制的逐页生图提示词。
```

适合没有接口、需要人工控制生成成本或习惯网页生图的使用者。离线提示词脚本本身不会上传资料；你手动提交至平台时由该平台处理。

### 2. 使用已有工具：由环境提供生图能力

例如：Codex 环境中**实际可用**的图像工具或 `imagegen` Skill、用户自行连接的图像 MCP 工具、其他智能体环境中的生图或编辑工具。这些只是接入示例，不是随仓库安装的依赖，也不保证任意版本环境都提供。

```text
使用 $ppt-elegance-skill，通过当前环境已有的图像工具生成。
阅读我的项目报告，制作10页蓝金科技风格技术讲解PPT。
先形成大纲，然后逐页生成并检查；系统截图必须使用原图。
如果没有可用的图像工具，请输出提示词，不要声称已经生成图片。
```

智能体需确认工具是否支持参考图、编辑和目标比例，并遵守该工具的配置方式。只有网页界面、没有可调用工具时，选择第一条路径。

### 3. 自行配置 API：使用自己的服务与额度

仓库提供一个协议范围明确的示例适配器。需要 Python 3.10+，用户自行提供服务地址、模型标识和环境变量密钥。完整步骤见 [API 指南](docs/API.md)。

```bash
python scripts/generate_image.py --config config.json --prompt-file work/prompts/P01.txt --out work/pages/P01.png --dry-run
python scripts/generate_image.py --config config.json --prompt-file work/prompts/P01.txt --out work/pages/P01.png
```

第一条只检查配置，不读取密钥或发请求；第二条会提交一次请求，可能收费。脚本不自动重试，不自动读取 `.env`，也不会读取其他工具的私有配置。

## 推荐图像模型

对于中文整页排版、参考风格和图片编辑，**建议优先评估 GPT Image 系列，例如你所选服务实际提供的 GPT Image 2**，同时用一页代表性内页验证文字和流程图质量。其他支持相应能力的模型也可以使用。

这是选型建议，不是质量保证、官方背书或对账号可用性的承诺。本版未完成该型号的官方接口现场核验；具体模型 ID、尺寸、编辑能力和费用请查服务方文档。不能仅凭显示名称填入 API 的 `model` 参数。

官方参考入口：[图像生成](https://platform.openai.com/docs/guides/image-generation)、[模型目录](https://platform.openai.com/docs/models)。本项目独立开发，与任何模型或平台提供方没有官方隶属关系。

## 安装与调用

**作为 Skill 使用：** 下载仓库或解压发布包，保留完整的 `ppt-elegance-skill/` 文件夹，其中 `SKILL.md` 应位于文件夹顶层。通过你的智能体客户端支持的本地 Skill 导入方式安装；也可让智能体明确读取该文件。

```text
请读取我提供的 ppt-elegance-skill/SKILL.md，并按它处理这次PPT任务。
```

若客户端使用目录发现机制，把完整文件夹放入客户端规定的 Skill 搜索目录，重新加载后确认列表出现 **PPT Elegance**。各客户端路径可能不同；本仓库不更改客户端配置、不自动安装其他 Skill。识别成功后可用 `$ppt-elegance-skill` 调用；仅在聊天里输入名称不保证未安装的客户端能发现文件。

**作为命令行工具使用：** 在仓库根目录运行下方命令，不需要安装智能体客户端。CLI 只处理 JSON 规格、提示词、图像和打包，不自动读取 Word/PDF/代码并编写内容。

```bash
python scripts/validate_spec.py examples/activity.json
python scripts/build_prompts.py examples/activity.json --out-dir work/activity-prompts
```

需要图片打包功能时：

```bash
python -m venv .venv
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

自然语言使用不要求你手写 JSON，智能体可以根据资料生成规格。命令行用户可以从示例修改。建议在项目副本中运行，输出放 `work/` 或 `outputs/`。

## 输入、输出与资料边界

建议提供：演讲场景、受众、页数/时长、参考风格、事实材料、真实照片或截图、需要保留的表述。缺失的日期、地点、人数、测试结果采用占位或注明未确定。

打包产物：`presentation.pptx`、`presentation.pdf`、`pages/`、`pages.zip`、`overview.jpg`、`manifest.json`。PPTX 带逐页备注。若插入原始截图，应检查合成后的最终页面。

API 路径只发送传入的提示词和配置参数；示例适配器不会自动读取或上传源文件。已有工具路径的数据去向由具体工具决定。密钥只放进环境变量或自行管理的秘密存储，不能放到提示词、GitHub、截图或报告里。

`.gitignore` 排除了真实配置、环境文件、输出和日志；它不能保护已提交到 Git 的秘密。发布前仍应检查待提交文件；若密钥曾被公开，应撤销并更换。

## 常见问题

- **文字不准、箭头错误？** 对照 `visible_text` 和流程关系复核，局部修正或重生成。模型输出不能替代事实检查。
- **接口不支持参考图？** 用选中风格的文字规范保持一致，或换支持参考图的已有工具；不要把文件路径当作参考图上传。
- **图片不是16:9？** 先明确重排或等比留边。打包器会拒绝明显不符比例的图片，避免直接拉伸和裁掉文字。配置示例中的1536×1024只是接口参数示例，不是16:9成品。
- **请求超时？** 先查服务端任务/账单再决定是否重试，避免重复计费。
- **接口返回 URL、任务 ID 或 JPEG？** 当前适配器只接受同步 base64 PNG，换适配器或已有工具；不会自动下载任意返回 URL。
- **能生成可编辑 PPT 吗？** 当前脚本输出整页图片。可使用原生演示文稿工具重建文字和图表，但那是另一条制作流程。
- **能直接发布 GitHub 吗？** 本仓库是准备好的源文件；发布仍需选择自己的仓库并执行上传。
