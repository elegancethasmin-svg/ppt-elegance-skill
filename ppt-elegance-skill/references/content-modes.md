# Content modes

Read the relevant mode only. Sequences are starting points, not mandatory slide counts. Use the user's audience, duration and available evidence.

| ID | Purpose | Typical narrative |
|---|---|---|
| `technical` | 技术讲解、系统答辩 | 问题 → 架构 → 关键机制 → 真实界面 → 部署 → 验证 → 下一步 |
| `activity` | 团日、校园、志愿活动 | 背景 → 目标 → 议程 → 学习/实践 → 记录 → 心得 → 行动 |
| `innovation` | 创新创业、产品提案 | 需求 → 用户 → 方案 → 产品流程 → 验证 → 假设 → 路线图 |
| `medical` | 医学、健康科普 | 问题 → 原理 → 证据/示例 → 适用边界 → 行动建议 |
| `heritage` | 文化传承、工艺介绍 | 起源 → 材料 → 工序 → 人物/器物 → 当代实践 → 传承行动 |

## Technical

Use source names, fields, inputs and outputs precisely. Separate design from implemented features. A historical test count is not production accuracy; mock UI latency is not a measured benchmark. Show numbered stages and explicit edge lists before creating workflow images. Local inventory mapping must not become Internet scanning in the illustration.

## Activity

First distinguish **planned**, **in progress**, and **completed** events. Record only supplied dates, organizers, location, attendance, photos and outcomes. Plans may use an agenda and expected outputs labelled as targets; completed-event recaps need documentary evidence. Do not generate a realistic group photo and imply those people attended. Attribute supplied quotes faithfully; offer draft speaking points as drafts, not quotes from named people.

## Innovation

Separate hypotheses, prototype capability and measured results. Market numbers, customers, revenue and partnerships require sources. Without metrics, show validation methods and pending questions rather than fabricated growth charts.

## Medical

Keep educational material distinct from individual clinical advice. Preserve source date, population and uncertainty for consequential claims. Do not add treatment success guarantees or present generated diagrams as diagnostic scans. Avoid irrelevant disclaimers when a simple factual caption suffices.

## Heritage

Attribute dates, origin stories and craft lineage. Avoid mixing unrelated regional/era motifs for decoration. Use supplied artifact photos as documentary material; mark generated atmosphere imagery as illustrative when it could otherwise be mistaken for a historical record.
